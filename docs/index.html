Engine Features

🔒

Docker-Based Sandboxing

Guest sessions and visitor widgets are forced into restricted Docker container runtimes (network blocked, CPU/Memory caps) to protect your host OS.

🛠️

Real Host Tool execution

Run bash, read/edit files, scrape websites via headless Chromium, and send SMTP emails automatically on your command.

🔌

Self-Writing Skills

Hot-reloads new skills written in Markdown mid-conversation. You can instruct NOVA to write its own plugins and load them instantly.
